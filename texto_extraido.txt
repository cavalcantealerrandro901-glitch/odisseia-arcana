Atue como um desenvolvedor especialista em
Discord.js v14.
Refatore o projeto do bot ODISSEIA ARCANA
para usar uma estrutura modular de comandos
em arquivos separados.
REQUISITOS DA ESTRUTURA:

1. Servidor Web Express (index.js):
Mantenha o servidor Express ativo
rodando na porta process.env.PORT ou
10000 para não dar o erro "Application
exited early" no Render.

2. Handler de Comandos Modular:
Crie uma pasta 'commands' para
armazenar os arquivos de comando
individualmente.
O index.js deve carregar dinamicamente
todos os arquivos .js dentro da pasta
'commands'.

3. Arquivos de Exemplo na pasta 'commands/':
commands/ping.js (Responde o ping/
latência do bot para O.ping e /ping).
commands/help.js (Menu de ajuda com
os sistemas do bot para O.help e /help).
commands/daily.js (Comando de resgate
diário de Almas).
commands/atm.js (Comando de ver o
saldo de Almas).

4. Suporte a Prefixos:
O bot deve aceitar os prefixos 'O.' e 'o.'.
Deve ser fácil adicionar novos arquivos de
comando na pasta 'commands' no futuro.

Crie/atualize o index.js e os arquivos da pasta
'commands' mantendo o código limpo e sem
erros de sintaxe.
